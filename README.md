# 📊 Customer Churn Prediction

## 📌 Problem Statement
Predict which customers are likely to stop using a service.

## 📂 Dataset
Telco Customer Churn Dataset (Kaggle)

## 🛠️ Tools & Technologies
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn

## ⚙️ Models Used
- Random Forest Classifier

## 📈 Evaluation Metrics
- Accuracy
- Recall
- ROC-AUC Score

## 📊 Results
- Achieved good accuracy in predicting churn customers
- Identified key features influencing churn

## 🔍 Insights
- Customers with higher monthly charges are more likely to churn
- Month-to-month contract users have higher churn rate

## 🚀 Future Improvements
- Use XGBoost for better performance
- Deploy using Streamlit

## 📌 Conclusion
This project helps businesses identify customers at risk and take preventive actions.
